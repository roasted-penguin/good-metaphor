# 0004 말풍선 테마는 관심사에 붙인다

- 상태: 채택 (2026-09-28)

## 배경
메이플 유저에게는 익숙한 느낌이 필요하지만, 메이플이 아닌 사용자 유입도 막으면 안 된다. 기존 가이드 사이트 UI는 따라 하지 않는다.

## 결정
- 그래프에 `theme` 필드. 메이플 공통 저장소는 `maple`, 사용자 관심사 기본값은 `neutral`.
- `maple`: 인게임 아이템 툴팁처럼 어두운 남색 말풍선, 잠재능력 등급색을 의미별로 쓴다(유니크 노랑 = 라벨, 레전드리 초록 = 근거, 에픽 보라 = 추상 태그, 레어 파랑 = 내 저장소), 주황은 버튼·스피너.
- `neutral`: 라이트/다크를 따르는 깔끔한 말풍선.
- 설정 화면은 테마와 무관하게 중립 디자인 + 주황 포인트.

## 참고
등급색은 나무위키 잠재능력 문서의 색 계열(레어 파랑, 에픽 보라, 유니크 노랑, 레전드리 초록)을 따르고, 값은 어두운 남색 배경에서 읽히도록 밝게 조정한 근사값이다.

2026-10-11 재확인: 공식 사이트 CSS나 인게임 툴팁의 공식 색상값은 공개된 곳을 찾지 못했다. 나무위키(https://namu.wiki/w/메이플스토리/잠재능력)의 다크 모드 값은 레어 `#66ffff`, 에픽 `#9966ff`, 유니크 `#ffcc00`, 레전드리 `#ccff00`이며, 이것도 위키 편집자가 고른 색이다. 현재 값(`#8fdcff`, `#d2b1ff`, `#ffcc33`, `#b9ef5a`)은 같은 계열이라 유지한다. 정확한 인게임 값이 필요하면 인게임 스크린샷에서 직접 픽셀 색을 딴다.
