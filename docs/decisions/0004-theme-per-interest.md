# 0004 말풍선 테마는 관심사에 붙인다

- 상태: 채택 (2026-09-28)

## 배경
메이플 유저에게는 익숙한 느낌이 필요하지만, 메이플이 아닌 사용자 유입도 막으면 안 된다. 기존 가이드 사이트 UI는 따라 하지 않는다.

## 결정
- 그래프에 `theme` 필드. 메이플 공통 저장소는 `maple`, 사용자 관심사 기본값은 `neutral`.
- `maple`: 인게임 아이템 툴팁처럼 어두운 남색 말풍선, 잠재능력 등급색을 의미별로 쓴다(유니크 노랑 = 라벨, 레전드리 초록 = 근거, 에픽 보라 = 추상 태그, 레어 파랑 = 내 저장소), 주황은 버튼·스피너.
- `neutral`: 라이트/다크를 따르는 깔끔한 말풍선.
- 설정 화면은 테마와 무관하게 중립 디자인 + 주황 포인트.

## 참고
등급색은 나무위키 잠재능력 문서 기준. 환산주스탯·공식 홈페이지 색상값은 작성 환경에서 접속이 막혀 직접 추출하지 못했다.
