# 0001 저장소를 공통 + 사용자 오버레이 두 층으로 나눈다

- 상태: 채택 (2026-09-28)

## 배경
PoC는 로그인 없이 바로 써 볼 수 있어야 하고, 커스텀 관심사는 로그인한 사용자만 가져야 한다.

## 결정
- 공통 저장소: 운영자가 관리하는 읽기 전용 그래프(PoC는 메이플스토리). 로그인 불필요.
- 사용자 저장소: 로그인한 사용자별 오버레이. 공통 그래프를 고치지 않고 위에 얹는다(추가 노드·태그, 숨김, 가중치, `useCommon:false`로 관심사 변경).
- 검색 직전에 `mergeGraphs(common, session ? overlay : null)`로 합친다.
- 사용자 노드 id는 `u:` 접두어로 충돌을 막고, 공통 태그 id는 그대로 참조할 수 있다.

## 결과
- 공통 그래프 버전을 올려도 사용자 데이터가 깨지지 않는다(없는 태그·끊긴 엣지는 병합 때 버림).
- 저장소 어댑터(`none` / `local-dev` / `remote`)만 바꾸면 서버를 붙일 수 있다.
