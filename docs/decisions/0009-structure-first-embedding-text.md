# 0009 임베딩 텍스트는 구조를 앞에, 태그에는 다른 분야 예문을 둔다

- 상태: 채택 (2026-10-18, T-113)

## 배경
실제 모델(e5-small q8) 평가에서 금융·경제 문장이 구조(손실 위험, 기댓값, 구간별 비용 증가)와 상관없이 `meso_inflation`·`meso`·`auction`으로 끌려갔다(혼합 hit@1 11/16, 금융 0/5). 노드 텍스트가 게임 용어(메소, 장비)로 가득해 "돈" 주제 유사도가 이겼고, 태그 설명 한 줄만으로는 다른 분야 문장과 거리가 멀었다.

## 결정
- **태그 텍스트** = `라벨: 설명` + `examples`(게임 밖 여러 분야의 짧은 예문 2~3개). 예문은 통제 어휘(규칙 9)를 늘리지 않고, 태그가 어떤 구조인지 보여 주기만 한다. 평가셋·검증셋 문장을 베끼지 않는다(단위 테스트의 3-gram 자카드 < 0.3).
- **노드 텍스트** = 노드 태그들의 태그 텍스트(예문 포함)를 앞에, `이름. 사실`을 뒤에. 게임 용어 비중을 낮춘다.
- **가중치** `directWeight 0.3`, `tagWeight 0.7`(이전 0.45/0.55). 직접 유사도는 아직 주제 쪽으로 쏠려 있어 태그 경유 비중을 높인다.
- **평가 고정**: q8은 활성값 양자화 스케일이 배치 단위라 같은 문장도 함께 묶인 배치에 따라 벡터가 달라진다(cos 0.9967). `tools/eval.mjs`는 확장과 같게 노드·태그는 한 배치, 질의는 한 문장씩 임베딩한다. 조정에 쓰지 않는 검증셋 `tools/eval-holdout.json`(14문장)을 함께 본다.

## 결과
- 평가셋 혼합 hit@1 11 → 13/16(금융 0 → 3/5), 검증셋 6 → 10/14(금융 2 → 4/5). 대체 임베더도 11 → 12/16, 6 → 10/14.
- 기준(13/16)을 겨우 넘었다. 세일·누진세는 여전히 틀리고, API 분당 상한 문장이 새로 틀렸다. 직접 비교만 쓰면 쏠림은 그대로다. 남은 수단(태그 점수 감점·상위 2개 평균, 질의 LLM 재작성, 판정 모델)은 T-113 할 일 (3)~(5)와 T-120.
- 노드·태그 텍스트가 바뀌면 벡터 캐시 키(sha1)가 바뀌어 첫 호버 때 다시 임베딩된다.
- 확장도 노드·태그를 한 배치로 임베딩하므로, 사용자 노드가 추가돼 일부만 다시 임베딩되면 벡터가 조금 달라질 수 있다(T-128).
- LightRAG 서버(ADR 0006)로 옮겨도 태그 예문은 추출·질의 키워드 프롬프트의 통제 어휘 설명으로 재사용할 수 있다.
