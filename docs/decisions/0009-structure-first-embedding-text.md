# 0009 임베딩 모델을 e5-base로, 텍스트는 구조를 앞에, 태그에는 다른 분야 예문을 둔다

- 상태: 채택 (2026-11-01, T-113, 사용자 결정)

## 배경
실제 모델(e5-small q8) 평가에서 금융·경제 문장이 구조(손실 위험, 기댓값, 구간별 비용 증가)와 상관없이 `meso_inflation`·`meso`·`auction`으로 끌려갔다(첫 평가 혼합 hit@1 11/16, 금융 0/5). 노드 텍스트가 게임 용어(메소, 장비)로 가득해 "돈" 주제 유사도가 이겼고, 태그 설명 한 줄만으로는 다른 분야 문장과 거리가 멀었다.

e5-small에서 텍스트·가중치만 고친 첫 판(PR #11 첫 판, 0.3/0.7)은 옛 평가셋 30문장에서 13/16까지 올랐지만, 잘 맞던 문장 2개가 틀려졌고 T-103의 처음 보는 문장에서는 기준선보다 못했다(12/19 → 9~11). e5-small은 유사도가 0.80~0.85에 몰려 있어 작은 조정에도 다른 문장이 흔들린다.

## 결정
- **임베딩 모델** `Xenova/multilingual-e5-base` q8(이전 e5-small). 접두어(`query: `·`passage: `)는 같다.
- **태그 텍스트** = `라벨: 설명` + `examples`(게임 밖 여러 분야의 짧은 예문 2~3개). 예문은 통제 어휘(규칙 9)를 늘리지 않는다. 평가셋·검증셋 문장을 베끼지 않는다(단위 테스트의 3-gram 자카드 < 0.3).
- **노드 텍스트** = 노드 태그들의 태그 텍스트(예문 포함)를 앞에, `이름. 사실`을 뒤에.
- **점수** 가중치는 그대로(`directWeight 0.45`, `tagWeight 0.55`), 경제 태그 감점 `tagPenalty: { inflation: 0.02, market_price: 0.02 }`. `retrieve()`에 `tagAgg`(`max`|`top2mean`)·`tagPenalty` 옵션이 있고 기본값은 이전과 같다.
- **판단 기준(사용자, 2026-11-01)**: 전에 맞던 문장이 틀려지는 것("회귀")은 문장 단위로 보이고, 전체로 많이 맞히면 바꾼다. 틀려진 문장은 따로 작업으로 고친다(T-135).

## 결과
| 실제 모델 | 평가셋 40(비유 있음 35) | 금융 12 | T-103 새 문장 19 | 검증셋 14 |
| --- | --- | --- | --- | --- |
| 이전 (e5-small, 예문 없음) | 23 (66%) | 4 | 12 | 6 |
| 이번 (e5-base + 예문 + 감점) | **30 (86%)**, hit@3 32 (91%) | **12** | **15** | **11** |

- 틀려진 4문장: 적금 → `starforce`, 팀장 결재 → `weekly_boss`, "Learning to code every day" → `weekly_boss`, 수술 역할 분담 → `weekly_boss`. `weekly_boss`는 태그가 3개라 "가장 높은 태그" 방식에서 1위 기회가 많다. T-135에서 고친다(태그 수 보정 실험은 회귀 3건으로 줄였지만 맞힘도 줄어 채택 안 함).
- 모델 용량 113MB → 266MB(첫 설치 다운로드가 길어진다). Node 측정으로 질의 1개 임베딩 4ms → 9ms, 노드·태그 36개 91ms → 172ms. 실제 크롬(wasm) 수치는 T-102에서 잰다.
- 회귀 가드 `tools/eval-guard.json`을 새 설정 기준 41문장으로 다시 만들었다(4개 빼고 16개 더함).
- 노드·태그 텍스트와 모델이 바뀌면 벡터 캐시 키(임베더 id + sha1)가 바뀌어 첫 호버 때 다시 임베딩된다.
- **평가 고정**: q8은 같은 문장도 함께 묶인 배치에 따라 벡터가 달라진다. 평가는 질의를 한 문장씩 임베딩한다(T-134). 확장 쪽은 T-128.
- 비유가 없어야 하는 문장의 1위 점수(0.66~0.80)가 맞힌 문장(최소 0.72)과 겹쳐 점수 임계값으로는 못 가른다. "근거 없으면 비유를 비우는" LLM 규칙(규칙 1)에 계속 맡긴다.
- LightRAG 서버(ADR 0006)로 옮겨도 태그 예문은 추출·질의 키워드 프롬프트의 통제 어휘 설명으로 재사용할 수 있다.
