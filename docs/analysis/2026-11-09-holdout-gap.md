# 홀드아웃 성적 차이 분석 (T-153, 2026-11-09)

홀드아웃(`tools/eval-unseen.json`) hit@1 13/20(65%)은 평가셋 40/44(91%)·검증셋 13/14(93%)보다 크게 낮다. 원인을 실제 확장(e5-base q8, 한 문장씩 임베딩) 기준으로 분석했다.

## 방법
- 홀드아웃 20문장을 시드 153으로 나눴다. A(선택용) 0,2,3,4,6,7,8,10,11,18 / B(마지막에 한 번만 채점) 나머지 10개.
- 후보는 A·평가셋·검증셋만 보고 골랐다. 채택 기준은 홀드아웃 +2, 회귀 0, 음성 6/6, 여유 < 0.005 문장 합계가 늘지 않음.

## 찾은 것
1. **sol_erda의 근거 없는 태그.** `scarcity_value`(희소성 가치)가 붙어 있었지만 facts에는 가격·거래가 없다. 희소성 예문 5개(중고·웃돈·가격)가 노드 텍스트에 들어가 가격 이야기에 끌렸고, 홀드아웃에서 엉뚱하게 1위가 3번(카메라 렌즈, 포토카드, Collectors) 나왔다. 이 태그 덕에 sol_erda가 맞힌 문장은 어느 셋에도 없다.
2. **예문이 평가 문장 쪽으로 골라졌다.** 어휘를 베낀 흔적은 없다(예문↔평가 문장 3-gram 자카드 최대 0.26). 하지만 T-135는 평가 문장 두 개(한정판 운동화, 팀장 결재)를 맞추려고 약 45개 변형을 시험해 예문 3개를 넣었다. 되돌리면 바로 그 문장만 틀린다. 그렇게 보강한 `scarcity_value`가 지금 가장 자주 엉뚱하게 1위를 차지하는 태그다(5회).
3. **태그 경계 겹침.** `diminishing_returns`의 설명 "단계가 오를수록"이 단계적 해금 문장(수영 초급반→중급반)을 끌어온다. 영어·경제 문장(투자 수익, 항공권 세일, 영화 촬영 역할)은 `expected_value`·`efficiency_metric`·`market_price`로 쏠리고, 점수대도 낮다.
4. **구조적 원인.** `nodeText`는 노드가 가진 태그의 예문을 전부 포함한다. 그래서 예문 한 줄이 그 태그를 가진 노드 여러 개를 함께 움직인다. 평가 문장에 맞춘 조정이 다른 문장에서 비선형으로 터지는 이유다.

## 열린 선택지 (이번에는 반영하지 않음)
- **노드 텍스트에서 태그 예문을 빼기**(태그 설명만 남김), 또는 **태그 벡터를 예문별 벡터의 최대값으로**: 예문 한 줄이 여러 노드를 흔드는 구조를 끊는다. 점수식 변경이라 별도 ADR과 전체 재측정이 필요하다.
- T-135 예문은 과적합 흔적이지만 지금은 가드가 보호하고 있다. 위 구조 변경과 함께 다시 볼 일이다.
- 경제·영어 문장 쏠림은 질의 재작성(정밀 모드) 쪽에서 다루는 편이 맞다.
