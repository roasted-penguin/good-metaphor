# 권한 사용 이유 (웹스토어 제출용)

웹스토어 개발자 대시보드 "개인정보 보호 관행" 탭의 칸에 그대로 붙여 넣을 수 있게 정리했어요. 기준은 `extension/manifest.json`(판 0.1.0)과 2026-11-09 코드예요. 권한을 바꾸면 이 문서도 함께 고쳐요.

## 단일 목적

좋은비유네용은 웹페이지에서 사용자가 고른 문장 하나를 사용자의 관심사(메이플스토리 또는 식당)에 빗대 한 줄로 풀어 주는 읽기 도우미예요. 사용자가 보조키(기본 Alt)를 누른 채 문장에 커서를 올리면, 확장 안에 번들된 관심사 그래프에서 구조가 비슷한 개념을 찾고, 사용자가 고른 AI 제공자에게 그 문장과 개념의 사실만 보내 쉬운 뜻과 비유를 받아 말풍선으로 보여 줘요. 이 밖의 기능(광고, 추적, 페이지 수정, 데이터 판매)은 없어요.

## permissions

| 권한 | 사용 이유 |
| --- | --- |
| `storage` | 사용자 설정(관심사, 띄우는 방법, 제외 사이트, AI 제공자와 API 키), 말풍선 피드백 기록, 검색용 벡터 캐시를 `chrome.storage.local`에 저장하고, 최근 결과와 요청 한도 대기 시간을 `chrome.storage.session`에 잠깐 둬요. 조직 배포 시 관리자 정책(`chrome.storage.managed`)도 읽어요. |
| `offscreen` | 문장 검색용 임베딩 모델(transformers.js, WebAssembly)을 서비스 워커에서 돌릴 수 없어서, 오프스크린 문서(`offscreen.html`, 사유 `WORKERS`)에서 실행해요. 화면에 보이지 않고 페이지 내용에 접근하지 않아요. |
| `unlimitedStorage` | 관심사 그래프의 개념·태그 벡터 캐시(기본 최대 2,000개, 768차원)와 피드백 기록(최대 500건, 문장 벡터 포함)이 기본 저장 한도(10MB)를 넘을 수 있어요. 캐시를 저장하지 못하면 호버할 때마다 임베딩을 다시 계산해 느려져요. 데이터는 이 기기에만 있어요. |
| `identity` | 관리자가 서버 계정 저장소(`userStore.adapter: "remote"`)를 켰을 때만 `chrome.identity.launchWebAuthFlow`로 로그인 창을 열어요. **주의: 스토어 빌드는 로그인이 꺼져 있어(`none`) 지금은 이 권한을 쓰는 코드가 실행되지 않아요.** 제출 전에 이 권한을 뺄지 정해야 해요(아래 "확인 필요"). |
| `activeTab` | 툴바 팝업을 열었을 때 그 탭의 주소(호스트)를 읽어 "이 사이트에서 끄기" 체크 상태를 보여 주고 제외 목록에 넣고 빼요. 팝업을 연 그 탭에만, 그 순간에만 쓰여요. |

## host_permissions

| 주소 | 사용 이유 |
| --- | --- |
| `https://api.groq.com/*` | Groq AI 제공자 호출(기본 제공자). 사용자가 키를 넣었을 때만 불러요. |
| `https://generativelanguage.googleapis.com/*` | Google Gemini AI 제공자 호출. 사용자가 키를 넣었을 때만 불러요. |
| `https://integrate.api.nvidia.com/*` | NVIDIA Build AI 제공자 호출. 사용자가 키를 넣었을 때만 불러요. |
| `https://api.openai.com/*` | OpenAI 제공자 호출. 사용자가 고르고 키를 넣었을 때만 불러요. |
| `https://api.anthropic.com/*` | Anthropic Claude 제공자 호출. 사용자가 고르고 키를 넣었을 때만 불러요. |
| `http://127.0.0.1:11434/*` | 사용자 컴퓨터에서 도는 Ollama(로컬 AI)를 다른 제공자가 모두 실패했을 때 마지막으로 불러요. 이 기기 밖으로 나가지 않아요. Ollama가 꺼져 있으면 건너뛰어요. |
| `https://huggingface.co/*`, `https://*.huggingface.co/*`, `https://*.hf.co/*` | 임베딩 모델 가중치(`Xenova/multilingual-e5-base`, 데이터 파일)를 처음 한 번 내려받아요. 코드는 받지 않아요(스크립트·wasm은 모두 확장에 번들). `*.hf.co`·`*.huggingface.co`는 Hugging Face가 파일을 내려주는 CDN 주소예요. |

AI 제공자는 사용자가 설정 화면에서 고른 제공자를 먼저 부르고, 실패(요청 한도·서버 오류·네트워크 오류)하면 관리자 설정(`config/admin.json` `fallbackChain`)의 다음 순위로 넘어가요. 키가 없는 제공자는 건너뛰어요.

## optional_host_permissions: `<all_urls>`

설치할 때는 요청하지 않아요. 사용자가 설정 화면에서 "OpenAI 호환 주소(OpenRouter, Ollama 등)" 제공자를 고르고 주소를 직접 넣어 저장할 때만, **그 주소의 출처 하나**(`https://example.org/*` 꼴)를 `chrome.permissions.request`로 물어봐요. 사용자가 거절하면 저장하지 않아요. 미리 알 수 없는 사용자 지정 AI 주소를 지원하려고 범위를 `<all_urls>`로 둔 것이고, 실제 허용은 사용자가 승인한 출처 하나뿐이에요.

## content_scripts: `matches: <all_urls>`, `all_frames: true`, `match_about_blank: true`

사용자가 어떤 페이지에서 읽다가 모르는 문장을 만날지 미리 알 수 없어서 모든 페이지에 콘텐츠 스크립트(`content.js`)를 넣어요. 기사 본문이 iframe 안에 있는 사이트(뉴스 위젯, 문서 뷰어 등)도 있어서 모든 프레임에 넣고, 프레임마다 자기 안에서 말풍선을 띄워요.

콘텐츠 스크립트가 하는 일과 하지 않는 일:

- **보조키를 누르기 전에는 페이지 내용을 읽어 보내지 않아요.** 평소에는 커서 좌표와 키 입력 여부만 봐요. 보조키(기본 Alt)를 누른 채 커서를 올린 순간 커서 아래 문장 하나, 그 앞 문장(최대 300자), 커서 아래 낱말, 페이지 제목(최대 120자)만 확장 서비스 워커로 보내요.
- 사용자가 설정에서 "머무르면 자동"을 직접 고른 경우에만, 보조키 없이 커서가 0.9초(설정 가능) 머물면 같은 내용을 보내요. 기본값은 보조키 방식이에요.
- **제외 사이트에서는 꺼져요.** 메일(Gmail, 네이버·다음 메일, Outlook), 로그인 페이지(Google·네이버·카카오·Microsoft 계정), 은행(KB·신한·우리·하나·농협·IBK·카카오뱅크·토스)이 기본 목록에 있고, 사용자가 팝업 "이 사이트에서 끄기"나 설정에서 더하고 뺄 수 있어요. iframe은 자기 주소와 최상위 페이지 주소 중 하나라도 제외 목록에 있으면 꺼지고, 서비스 워커도 보낸 프레임의 주소를 한 번 더 확인해 막아요.
- **비밀번호 칸이 있는 폼 안의 문장은 읽지 않아요**(같은 출처 iframe이 그런 폼 안에 있을 때도). 입력칸·textarea·편집 가능한 영역·코드 블록의 글자도 읽지 않아요.
- 페이지의 DOM을 바꾸지 않아요. 말풍선은 Shadow DOM 안에 그리고, 문장 강조는 CSS Highlight API로 해요.
- 원격 코드를 불러오지 않아요. 모든 스크립트는 확장 안에 있어요.

## 확인 필요 (제출 전에 사람이 정할 것)

1. **`identity`가 스토어 빌드에서 쓰이지 않아요.** `chrome.identity`를 부르는 곳은 `extension/lib/stores.js`의 서버 계정 어댑터(`remote`)뿐이고, 스토어 빌드는 `userStore.adapter`가 `none`이라 실행되지 않아요. 웹스토어는 쓰지 않는 권한을 반려 사유로 보기 때문에, 로그인(D-2, L3)이 생기기 전에 올린다면 스토어 빌드 manifest에서 빼는 것을 권해요. 뺄지는 아직 정하지 않았어요(이 문서는 지금 manifest 그대로를 설명해요).
2. `host_permissions`의 OpenAI·Anthropic은 기본 체인에 없고 사용자가 고를 때만 써요. 심사에서 물으면 "사용자가 고를 수 있는 제공자"라고 답하면 돼요.
