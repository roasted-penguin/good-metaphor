비유 도우미 · 크롬 확장 PoC

모르는 문장에 커서를 올리면,
내가 아는 세계로 풀어 줘요

관심사를 그래프로 저장해 두고, 문장과 구조가 같은 개념을 찾아 그 사실만 근거로 한 줄 비유를 만듭니다. 기본 관심사는 메이플스토리예요.

문장에 커서를 올리거나 눌러 보세요. 실제 확장에서는 Alt 누른 채 올려요.

경제 기사 한 대목

레버리지는 이익과 손실을 모두 키워서 작은 가격 하락에도 원금을 잃을 수 있다. 중앙은행이 돈을 많이 찍어내면 물가가 오르고 화폐 가치가 떨어진다.

한편 API 서버는 분당 요청 수에 상한을 두어 한 사용자가 자원을 독점하지 못하게 한다. 한정판 운동화는 구하기 어려워 되팔 때 가격이 크게 오른다.

예시 답변은 설명을 위해 미리 작성한 것이에요. 근거 칩은 실제 공통 그래프의 노드와 태그 이름입니다.

작동 방식

커서 한 번에 일어나는 일

  1. 문장 찾기커서 아래 글자를 찾아 문장과 단어, 앞 문장까지 잘라 냅니다. 페이지는 건드리지 않고 강조만 겹쳐 그려요.
  2. 구조가 같은 개념 찾기문장을 벡터로 바꿔 관심사 그래프와 비교합니다. 개념을 직접 비교하는 것에 더해, 추상 태그를 한 번 거쳐 같은 구조를 가진 개념으로 이동해요.
  3. 근거로 비유 만들기상위 3개 개념의 사실만 AI에 건네고, 그중 가장 잘 맞는 하나로 쉬운 뜻과 비유를 쓰게 합니다.
  4. 검증 후 보여 주기AI가 후보에 없는 개념을 댔으면 비유를 숨기고 뜻만 보여 줘요. 말풍선에는 근거 개념과 태그를 늘 함께 표시합니다.
인프라 구성

서버 없이 브라우저 안에서 돌아요

지금은 사용자 크롬 안에서 거의 모든 일이 끝나고, 밖으로 나가는 건 모델 가중치 다운로드(처음 한 번)와 비유 생성 호출뿐이에요. 로그인과 공통 저장소 배포는 Phase 2에서 붙습니다.

런타임 구성

지금 동작 Phase 2 계획 호버 한 번의 흐름: 문장 → 임베딩 → LLM → 말풍선

개발 흐름

다음 아키텍처 · 설계

LightRAG로 그래프를 키우고, 추출은 내 맥에서

손으로 쓴 개념 18개 대신 가이드 문서에서 그래프가 자라게 해요. 가장 비싼 일인 엔티티·관계 추출은 내 M2 맥의 로컬 모델이 Tailscale 너머로 맡고, 호버 경로에는 맥이 없어서 맥이 꺼져 있어도 비유는 나옵니다.

추출은 맥, 호버는 클라우드맥(Ollama gemma4:12b)은 점심·밤 시간창에만 추출 큐를 비워요. 호버 때는 Gemini가 키워드와 비유를 만들어요.
추상 태그 = high-level 키워드관계에 붙는 주제 키워드를 통제 어휘 18개로 고정해서, 금융 문장과 메이플 개념이 "기간당 한도" 같은 같은 말로 만나요.
월 약 $31EC2 t4g.medium 한 대, Tailscale 무료, Gemini 무료 티어. 로그인을 열면 t4g.large + Postgres로 약 $55.

LightRAG 전환 후 구성

인터넷 (HTTPS) 테일넷 안에서만, 공개 포트 없음 선택한 경로의 요청 흐름

호버 한 번: 확장 → analogy-api → Gemini가 키워드를 뽑고 → LightRAG가 두 워크스페이스를 검색 → Gemini가 근거 안에서만 비유를 써요. 자세한 설계는 설계 페이지(원본 architecture-lightrag.md)에 있어요.

저장소

로그인 없이 바로, 로그인하면 내 것까지

공통메이플스토리 그래프

  • 누구나 로그인 없이 사용
  • 개념 18개 · 추상 태그 18개 · 연결 12개
  • 운영자만 수정, 패치로 바뀌는 수치는 넣지 않음

내 저장소로그인한 사용자 전용

  • 내 개념·태그 추가, 공통 개념 숨기기
  • 관심사 자체를 바꾸기 (예: 축구)
  • 공통 그래프 위에 겹쳐서 함께 검색
틀린 비유 막기

억지 비유보다 비유 없음이 낫다

  • 관심사 쪽 내용은 그래프 사실만AI가 게임 수치나 규칙을 지어내지 못하게, 검색된 개념의 사실만 건넵니다.
  • 근거 밖 답은 숨김AI가 고른 개념이 후보 목록에 없으면 비유를 보여 주지 않아요.
  • 맞는 게 없으면 비움구조가 맞는 개념이 없으면 쉬운 뜻만 보여 줍니다. 위 데모에서 축구로 바꿔 보면 확인할 수 있어요.
