---
description: 실제 임베딩 모델로 검색 품질을 평가하고 EVAL_LOG에 기록한다
argument-hint: "[메모]"
---

1. `npm run eval -- -v`를 실행해. 모델 다운로드에 실패해서 대체 임베더로 바뀌면 멈추고 알려 줘(대체 임베더 결과를 실제 결과로 기록하지 말 것).
2. 가중치 설정 세 가지(직접만 / 태그만 / 혼합)의 hit@1, hit@3과 추상 태그 top-1 정확도를 `docs/EVAL_LOG.md` 표에 한 줄 추가. 메모 칸: $ARGUMENTS
3. 틀린 문장들을 보고 공통 원인을 2~3개로 묶어 설명해(예: 영어 문장, 특정 태그 설명이 너무 추상적).
4. 관문(혼합 hit@1 ≥ 75%, hit@3 ≥ 90%)을 넘었는지 말하고, 못 넘었으면 `docs/TASKS.md` T-103의 시도 순서 중 다음 것을 제안해.
