---
description: 공통 저장소(메이플스토리) 그래프에 개념 노드를 안전하게 추가한다
argument-hint: "<개념 이름, 예: 에디셔널 잠재능력>"
---

먼저 `git fetch origin && git switch -c task/data-<영문-슬러그> origin/dev`로 브랜치를 만든 뒤, 공통 그래프 `extension/data/common/maplestory.json`(식당이면 `restaurant.json`)에 "$ARGUMENTS" 노드를 추가해. 이 파일은 모든 사용자가 보는 사실 근거라서 아래 규칙을 지켜.

1. **사실 확인** 공식 가이드·패치 노트(식당은 공공 자료)를 먼저, 없으면 출처 정책(`tools/source-policy.json`)의 커뮤니티(메이플: 나무위키·인벤 메이플, 식당: 나무위키·티스토리·브런치·다음 뉴스)를 한 쪽씩 읽고 facts를 2~3개 문장으로 쓴다(ADR 0016).
   - **사실만, 우리 문장으로.** 원문 문장·표를 옮기지 않고, 페이지 글을 파일·커밋·대화 기록에 남기지 않는다(D-5). 목록·검색을 따라가며 긁지 않는다(robots 준수, 한 쪽씩).
   - 커뮤니티 문서에는 멸칭·실존 인물·확률표·가격이 많다. 그런 말은 사실로 옮기지 않는다(규칙 2·11). 식당은 특정 가게·브랜드 이름도 금지.
   - 시스템의 구조만 쓴다. 확률표, 최대 단계, 가격, 이벤트 날짜처럼 패치로 바뀌는 수치는 넣지 않는다.
   - 확신이 없는 문장은 넣지 않는다. 출처를 못 찾으면 멈추고 알려 줘.
   - 문장 끝은 "~다."로 통일.
2. **태그** 기존 태그(`extension/data/common/tags.json`, 규칙 9)에서 골라 노드 `tags`에 id만 적는다. 새 추상 태그가 꼭 필요하면 `tags.json` **맨 뒤에** 분야 중립적인 설명(`desc`)으로 추가하고(중간에 넣으면 순서가 바뀌어 검색 순위가 흔들린다, ADR 0012), 이 태그를 쓸 수 있는 다른 분야 예를 두 가지 들어 줘.
3. **출처·검수 날짜(T-118, ADR 0016)** `sources`에 **실제로 열어 내용을 확인한** 페이지 URL, `verifiedAt`에 확인한 날(YYYY-MM-DD).
   - 공식(메이플 `maplestory.nexon.com`, 식당 `*.go.kr` 등)만이면 그대로.
   - 커뮤니티 URL을 하나라도 넣으면 노드에 `"sourceKind": "community"`(키 순서 `sources` 뒤)를 쓰고, **교차 확인**: 공식 URL 1개 이상, 또는 서로 다른 커뮤니티 사이트 2곳(같은 플랫폼 두 글은 한 곳)이 같은 사실을 말해야 한다. 공식과 어긋나면 공식을 따른다.
   - 정책 밖 사이트(네이버 블로그·뉴스·카페 등)는 넣지 않는다. 교차 확인할 출처를 못 찾으면 멈추고 알려 줘. 어기면 그래프 테스트(`checkNodeSources`)가 실패한다.
4. **엣지** 기존 노드와의 관계를 짧은 동사구(`rel`)로 1~2개.
5. `version`의 날짜·번호를 올린다. 태그를 바꿨으면 `tags.json`의 `version`도 올린다(서버·확장 결과 캐시 키에 태그 판본이 들어가 그것만으로 캐시가 갈린다).
6. `npm run test:unit`(그래프 무결성 검사 포함)과 `npm run eval:fallback -- --baseline`을 돌린다(맞던 문장을 잃으면 실패. 받아들이면 `--write-baseline`으로 기준선을 다시 써 같이 커밋). 실제 모델을 쓸 수 있으면 `npm run eval`.
   - 노드·태그 예문을 바꾸면 `npm run eval -- --holdout -v`로 홀드아웃(`tools/eval-unseen.json`)도 돌려 순위가 떨어지지 않는지 본다(T-150). 홀드아웃 문장은 예문을 고를 때 보지 않는다.
7. 커밋 메시지: `data: 공통 그래프에 <개념> 추가`. 사용한 출처 링크를 커밋 본문에 남긴다.
8. `/ship` 절차로 push 후 dev로 PR. PR 본문에 출처 링크와 추가한 facts 전문을 넣어 검수자가 바로 확인할 수 있게 한다.
